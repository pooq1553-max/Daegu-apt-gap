# 대구 평형 왜곡

대구 도심 **준공 10년 이내(2017년~) 아파트**에서, 같은 단지 안의 **59㎡ · 74㎡ · 84㎡** 실거래 중앙값을 비교해
**어느 평형이 상대적으로 싼지** 보여주는 웹앱입니다. 폰 홈화면에 추가하면 앱처럼 열립니다(PWA).

- 서버비 0원: **GitHub Pages**(정적 호스팅) + **GitHub Actions**(매일 1회 수집)
- 데이터: **국토교통부 실거래가 공개시스템**(rt.molit.go.kr) 아파트 매매 내려받기 원자료. API 키·로그인 불필요
- 매일 16:00(KST) 자동 갱신, 실패하면 기존 데이터를 유지

## 판정 규칙

| 판정 | 조건 | 뜻 |
|---|---|---|
| **84㎡ 추천** | 59/84 ≥ 80%, 또는 59㎡ 없음 + 74/84 ≥ 93% | 59·74㎡가 84㎡ 값에 가깝게 불려 84㎡가 단가상 유리 |
| **59㎡ 추천** | 59/84 ≤ 70% | 59㎡가 눌려 있어 실거주 시 59㎡ 메리트 큼 |
| **관찰** | 70% < 59/84 < 80% | 시장 정상 범위 |
| **표본 부족** | 비교하는 두 평형 중 하나가 3건 미만 | 판정 보류 |

시장 정상선은 세 평형이 모두 3건 이상 거래된 단지들의 비율 **중앙값**으로 매번 다시 계산합니다
(2026-11-18 기준 59/84 = 75.1%, 74/84 = 88.6%).

## 집계 기준

- 대구광역시 7개 구(중구·수성구·남구·달서구·북구·동구·서구), 달성군·군위군 제외
- 건축년도 2017년 이후
- 전용 55~66㎡ = 59형, 66~79㎡ = 74형, 79~92㎡ = 84형
- **해제(취소) 신고 계약 제외**, **1~2층 거래 제외** — 이 둘이 비율을 최대 10%p까지 흔듭니다
- 대표값은 **중앙값**(이상거래·특수관계 거래 영향 축소), 최근 6개월 비율 병기

## 파일 구성

```
index.html                모바일 퍼스트 화면
style.css, app.js         스타일·렌더링(프레임워크 없음)
manifest.webmanifest, sw.js   PWA(홈화면 추가·오프라인)
data/apartments.json      단지별 통계 + 판정 (자동 생성)
tools/update_data.py      국토부 CSV 수집 → 집계 → apartments.json
.github/workflows/update-data.yml   매일 16:00 KST 자동 갱신
```

## 직접 갱신하기

```bash
python3 tools/update_data.py                          # 최근 12개월 자동 수신
python3 tools/update_data.py --period 2025-11-18 2026-11-17
python3 tools/update_data.py --csv raw.csv            # 이미 받은 CSV로 생성
```

## 한계

- 이 비교는 **같은 단지 안에서 어느 평형이 상대적으로 싼가**만 봅니다. 단지 간 비교는 입지·학군·연식이 섞여 별도 판단이 필요합니다.
- 신고는 계약 후 30일 내라 최근 1~2개월은 과소 집계됩니다.
- 향·동·관리비·학군·입주 물량·금리는 반영하지 않았습니다.
- 참고용이며 법적 효력이 없습니다.
